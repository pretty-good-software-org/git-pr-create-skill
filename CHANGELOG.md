# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html), and is generated by
[Changie](https://github.com/miniscruff/changie).

## [1.2.1] - 2026-11-09
### Changed
- The example video caption uses neutral app text.

## [1.2.0] - 2026-11-06
### Added
- Attach an existing bug or before/after recording to a fix pull request with `gh pr create` or `gh pr edit --attach`
  (GitHub CLI 2.99.0 or newer), after checking its frames, format, and GitHub's size limit. Without `--attach`, create
  the pull request without the video and hand the file to the user. Recordings are attached only with the user's
  approval, and refreshes keep an existing attachment.

## [1.1.0] - 2026-09-25
### Added
- Create or refresh pull request metadata against the live net diff, keep manual notes, inspect the checks on the
  current head, and fix reproducible failures within a bounded number of cycles, without bypassing checks or merging.
- Summarize a live pull request's changed files with `gh pr view`, and tell GitHub CLI diff flags apart from Git's.

## [1.0.1] - 2026-07-26
### Fixed
- Pull request titles and bodies describe the final net diff, tell validation evidence apart from shipped artifacts,
  and leave out discarded iterations and brittle process details.

## [1.0.0] - 2026-02-20
### Added
- Create GitHub pull requests with a structured title and body.
