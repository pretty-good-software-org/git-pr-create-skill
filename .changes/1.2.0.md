## [1.2.0] - 2026-11-06
### Added
- Attach an existing bug or before/after recording to a fix pull request with `gh pr create` or `gh pr edit --attach`
  (GitHub CLI 2.99.0 or newer), after checking its frames, format, and GitHub's size limit. Without `--attach`, create
  the pull request without the video and hand the file to the user. Recordings are attached only with the user's
  approval, and refreshes keep an existing attachment.
